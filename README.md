# bleach-autofarm

A small desktop app that auto-clicks the repetitive menu/dialogue buttons in
**Bleach: Brave Souls** (Skip, Tap Screen, Quest Clear banner, Close, Next
Quest, Prepare for Quest, Start Quest), so you
can idle through story stages or repeat-farm a cleared stage unattended.

![status](https://img.shields.io/badge/status-personal--project-blue)

## What it does
- Detects and clicks known menu/dialogue buttons by matching them against
  reference images captured from the game.

## Get it
Download from releases tab

## How to Run
With the game running, click **Start**. The status dot goes green while
running. **Pause** freezes it in place, **Stop** ends the session.

## ⚠️ A note on account risk
Automating input like this is against Bleach: Brave Souls'
Terms of Service; only use it on your account if you're comfortable putting
it at risk, and don't leave it running unattended for long stretches without
thinking through that tradeoff.
